# ОВТ — Food Construct

Учебный проект компании доставки бизнес-ланчей. HTML, CSS и JavaScript без фреймворков; Bootstrap 5 используется только в лабораторной 10.

## История работ

Каждая лабораторная развивается из предыдущей. Её состояние сохранено в ветке `lab-NN`; последняя версия находится в `main`.

## Требования и сдача

- [Введение](https://mospolytech-web-course.netlify.app/task0)
- [Требования](https://mospolytech-web-course.netlify.app/requirements)
- Проверки: W3C Nu, HTMLHint, ESLint.
- Для сдачи нужны ссылки на опубликованный сайт и репозиторий, а также доступ преподавателей.
- API-ключ из СДО не должен попадать в Git. Он вводится в браузере для текущей сессии.

Экзаменационный проект в этот репозиторий не включён: его условия запрещают AI-генерацию кода.
